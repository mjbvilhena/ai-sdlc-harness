# Conventional Commits Rule (GitHub Copilot)

When generating a commit message:

1. Use the Conventional Commits format: `<type>[optional scope]: <description>`
2. Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `chore`.
3. The description must be in the imperative, present tense ("add feature", not "added feature").
4. Do not capitalize the first letter of the description.
5. Do not end the description with a period.
