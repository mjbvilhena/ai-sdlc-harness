# Definition of Done: Hotfix

A production hotfix is considered "Done" when:
1. **Criticality Verified**: The issue is confirmed as Sev-1/Sev-2 requiring immediate resolution.
2. **Minimal Change**: The code change is the absolute minimum required to mitigate the issue.
3. **Approved**: Reviewed and approved by an Engineering Manager or Tech Lead.
4. **Deployed**: Pushed directly to production and confirmed resolved by monitoring tools.
5. **Postmortem Scheduled**: A calendar invite for the incident postmortem is created.
