# Definition of Done: Feature

A feature is considered "Done" when:

1. **Code Complete**: All acceptance criteria outlined in the ticket are met.
2. **Tested**: Unit and integration tests are passing. Code coverage > 80%.
3. **Reviewed**: Approved by at least one other engineer.
4. **Documented**: Any new APIs or systems are documented.
5. **CI/CD**: Builds pass successfully and branch can be merged without conflicts.
