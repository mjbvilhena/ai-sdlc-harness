# Definition of Done: Epic

An Epic is considered "Done" when:
1. **Features Complete**: All underlying user stories and tasks are completed and merged.
2. **Integration Tested**: End-to-end (E2E) testing validates the entire flow.
3. **Documentation**: User-facing documentation and internal architecture docs are updated.
4. **Stakeholder Sign-off**: Product Management and relevant stakeholders have accepted the deliverables.
5. **Rollout Plan**: Feature flags or rollout strategies are configured and ready.
