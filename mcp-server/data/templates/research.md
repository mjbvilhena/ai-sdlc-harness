# Research Report

Structured findings, options, and recommendations for a given topic or problem. Pair with skill `sdlc-researcher`.

**Quality bar:** Cross-referenced findings from authoritative sources. Clear distinction between facts, hypotheses, and general opinions. Actionable options with objective pros and cons.

## Metadata

| Field | Value |
|---|---|
| Topic | subject of the research |
| Domains | business domains fetched via MCP |
| Layers | architectural layers fetched via MCP |
| Primary Objective | e.g., tool selection, architecture decision, problem analysis |

A concise, one-paragraph summary of the research findings and the ultimate recommendation.

## Anti-patterns

- Recommending an option without acknowledging its tradeoffs.
- Relying on a single source or vendor documentation without independent validation.
- Presenting hallucinations or unsupported claims about third-party capabilities.
