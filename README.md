# AI SDLC Harness

A meta-harness for the Software Development Life Cycle (SDLC) that creates, manages, and deploys custom skills and agents into various AI agentic harnesses.

## Supported Harnesses
- **Claude Code**
- **GitHub Copilot (ghcp)**
- **Cursor**
- **Antigravity (agy)**

## Vision
This project serves as an installable product that provides a universal layer for defining AI skills and agent behaviors once, and compiling/deploying them into the specific formats required by different AI IDEs and CLI tools.

## Installation
```bash
pip install -e .
```

## Usage
```bash
harness --help
```
